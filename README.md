# link-snapshot

Desktop tool to paste a list of URLs and save full-page screenshots (and optional HTML) to a folder you choose.

## Planned features

- Paste URLs (one per line)
- Select output folder
- Full-page PNG screenshots
- Optional HTML export

## Status

Project scaffold only — implementation not started yet.
